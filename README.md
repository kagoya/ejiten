# 春の教室：絵辞典プロトタイプ

12場面のうち「春の教室」の1ページ。11語について、日本語とブラジル・ポルトガル語を表示・再生する。

## 操作

- 絵の対象や番号、単語一覧を選ぶと、その対象が強調され、選択中の言語の音声が流れる。
- 再生カードから両言語を個別に聴ける。「ゆっくり聴く」で速度を切り替える。
- 絵は100〜300%に拡大できる。拡大後はスクロールで移動でき、単語一覧からの選択で対象に移動する。
- 「元の絵を見る」で手描き原画と比較できる。
- スマートフォンでは単語一覧が下に並ぶ。キーボードでも選択可能。

## 素材

イラスト：imagegenの組み込みツールで新規生成。原画 `../ejiten/image/kotoba/ejiten03.png` を参照し、構図をおおむね維持して文字を除いた。生成PNG原本は `dist/assets/classroom-generated.png`、配信用はWebP。生成指示は `image-prompt.txt` に記録。

音声：既存録音は一切使用していない。edge-tts 7.2.8経由でMicrosoft Edgeオンライン音声合成を使い、新しい22件のMP3を生成した。日本語は `ja-JP-NanamiNeural`、ブラジル・ポルトガル語は `pt-BR-FranciscaNeural`、生成時の速度は-15%。台本・設定・生成日時を `dist/audio/manifest.json` に記録。品質評価と利用条件の確認を含む本番用音声サービスの選定は別途行う。

訳語：原画の11語を採用。女性の先生はprofessora、クレヨンはgiz de cera。今回の音声と訳語は専門話者の校正前の試聴用。ブラウザーでMP3の読込みと再生を検証しているが、発音の正確さを保証する検証は未実施。

## 起動

`dist/index.html` は直接開ける。HTTPで試す場合は、このディレクトリで `python -m http.server 8765 --bind 127.0.0.1 --directory dist` を実行して `http://127.0.0.1:8765/` を開く。

`dist` がサイト配信ファイル一式。元の絵辞典のHTML・画像・音声は変更していない。

## 検証

`tools/verify.mjs` はデスクトップ、390px幅、横向きでの操作、日葡の音声再生、22音声のメタデータ、拡大リセット、原画ダイアログ、キーボード操作、横はみ出しを検査する。実行環境はWindowsのEdgeと同梱Playwright。結果は `qa/report.json`、スクリーンショットは `qa/desktop.png` と `qa/mobile.png`。iPhone・Android実機での確認は未実施。
