# ぽるとがるご にほんご ことばえじてん（デジタル版）

絵を選んで日本語とブラジルポルトガル語のことばを聴ける、デジタル絵辞典です。四季の12場面に、137語・短文と両言語の音声274件を収録しています。パソコンとスマートフォンで利用できます。

[絵辞典をひらく](https://kagoya.github.io/ejiten/)

## 使い方

- 表紙画像を押すと、画像付きの目次が開きます。好きな場面を選んでください。
- 絵の対象・番号・単語一覧を選ぶと、対応することばの音声が流れます。
- 日本語とポルトガル語を切り替えられます。「ゆっくり聴く」で再生速度を変更できます。
- 絵を拡大して細かなものを確認できます。「元の絵を見る」で手描きの原画も表示できます。
- 「前の場面」「次の場面」、場面選択、目次から各場面へ移動できます。「表紙」で入口に戻れます。

## クレジット

原著『ぽるとがるご にほんご ことばえじてん』（2020年2月28日初版発行）の場面構成をもとに制作しています。場面イラストと音声には新しく生成したものを使用し、表紙・背表紙・裏表紙と比較用の原画には原著の画像を使用しています。

デジタル版制作：仁愛大学子ども教育学科 篭谷隆弘

原著の制作担当者・発行情報は、[クレジットページ](https://kagoya.github.io/ejiten/credits.html)をご覧ください。
