# ぽるとがるご にほんご ことばえじてん（デジタル版）

絵を選んで日本語とブラジルポルトガル語のことばを聴ける、デジタル絵辞典です。四季の12場面に、137語・短文と両言語の合成音声を収録しています。両言語に普通・ゆっくりの2種類の音声があります。パソコンとスマートフォンで利用できます。

[絵辞典をひらく](https://kagoya.github.io/ejiten/)

## 表示の切り替え

ページ上部の「表示 / Visualização」で4種類の画面を選べます。選んだ表示は同じブラウザーに保存されます。

- [日本語中心](https://kagoya.github.io/ejiten/?view=ja)：従来の詳しい画面です。
- [ポルトガル語中心](https://kagoya.github.io/ejiten/?view=pt)：案内と単語表示をポルトガル語中心にし、タップ時の音声もポルトガル語から始まります。
- [かんたん版](https://kagoya.github.io/ejiten/?view=kids)：幼児向けに説明を減らし、大きな絵・音声ボタン・矢印・画像付き目次で操作できます。日本語とポルトガル語の音声を選べます。

- [かんたん版（ポルトガル語）](https://kagoya.github.io/ejiten/?view=kids-pt)：大きなボタンと少ない説明のまま、ポルトガル語の案内・場面名・音声から始まります。

## 使い方

- 表紙画像を押すと、画像付きの目次が開きます。好きな場面を選んでください。
- 絵の対象・番号・単語一覧を選ぶと、対応することばの音声が流れます。
- 日本語とポルトガル語を切り替えられます。「ふつう」「ゆっくり」で読み上げの速さを選べます。
- 絵を拡大して細かなものを確認できます。「元の絵を見る」で手描きの原画も表示できます。
- 「前の場面」「次の場面」、場面選択、目次から各場面へ移動できます。「表紙」で入口に戻れます。

## クレジット

原著『ぽるとがるご にほんご ことばえじてん』（2020年2月28日初版発行）の場面構成をもとに制作しています。場面イラストと音声には新しく生成したものを使用し、表紙・背表紙・裏表紙と比較用の原画には原著の画像を使用しています。

音声：Fish Audio S2.1 Pro。日本語は「女性アナウンサー（ベテラン）」、ブラジルポルトガル語は「Beatriz (Brasil)」を使用しています。10項目以上をカンマでつなげてまとめ読みし、分割して普通・ゆっくりの音声を用意しています。短文は文ごとに生成しています。

デジタル版制作：仁愛大学子ども教育学科 篭谷隆弘

原著の制作担当者・発行情報は、[クレジットページ](https://kagoya.github.io/ejiten/credits.html)をご覧ください。
