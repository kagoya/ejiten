# ことばの絵じてん：日本語 × Português

四季の全12場面、137語・短文、日本語・ブラジルポルトガル語の新規生成音声274件を収録。

[確認用サイト（本人限定）](https://kotoba-classroom-prototype.kagoya.chatgpt.site)

## GitHub Pages

公開先は https://kagoya.github.io/ejiten/ 。`.github/workflows/pages.yml` が `main` へのpushごとに `dist/` をGitHub Pagesへ配信する。手動実行にも対応。リポジトリの Settings → Pages → Source は「GitHub Actions」を選ぶ。

ページ、画像、音声のパスは相対指定のため、`/ejiten/` 配下でも動作する。イラスト原稿や制作スクリプトはPagesへの配信対象に含めない。

## 操作

- 「前の場面」「次の場面」、場面選択、画像付きの「目次」から全12場面に移動できる。
- URLの `#scene-03`〜`#scene-14` で場面を直接指定できる。ブラウザーの戻る・進むにも対応。
- 絵の対象や番号、単語一覧を選ぶと、その対象が強調され、選択中の言語の音声が流れる。
- 再生カードから両言語を個別に聴ける。「ゆっくり聴く」で速度を切り替える。
- 絵は100〜300%に拡大できる。スクロールで移動でき、単語一覧からの選択で対象に移動する。
- 「元の絵を見る」で各場面の手描き原画と比較できる。
- スマートフォンでは単語一覧が下に並ぶ。キーボードでも選択可能。
- 場面の移動では再生を停止し、拡大を全体表示に戻す。選んだ言語・低速設定と場面ごとの試聴数は、そのページを開いている間保持する。

## 素材とデータ

- `scene-data/scene-NN.json`：場面名、対訳、対象座標、読み上げ台本。03は既存試作の `dist/words.js` から構成する。
- `dist/scenes.js` と `dist/scenes.json`：上記を統合した配信用データ。`tools/build_scenes.mjs` で再作成する。
- `artwork/`：組み込みimagegenで新規生成した12枚のPNG原本。元の手描きイラストを参照し、構図と学習対象をおおむね維持した。文字は画像から除き、画面で別に表示する。
- `dist/assets/`：軽量な配信用WebPと、原画比較用PNG。プロトタイプ03の生成指示は `image-prompt.txt`、残り11場面は `scene-data/scene-NN-prompt.txt`。
- `dist/audio/`：新規生成した274件のMP3。既存録音は一切使用していない。
- `dist/audio/manifest.json`：言語、台本、声、生成設定・日時、校正状態。

音声生成はedge-tts 7.2.8経由のMicrosoft Edgeオンライン音声合成。日本語は `ja-JP-NanamiNeural`、ブラジルポルトガル語は `pt-BR-FranciscaNeural`、生成速度は-15%。03の22件は前回生成した音声を保持し、残り252件を新規生成した。

明白な元資料の誤記を補正した（例：ぞら→そら、しゃべる→シャベル）。日本の冬とブラジルの夏の対比も保持。語・短文の最終言語校正と本番用音声サービスの利用条件確認は未実施。生成音声についても発音・アクセントの正確さを保証する専門話者校正は今後の作業。

## 起動と更新

`dist/index.html` は直接開ける。HTTPで試す場合は、このディレクトリで `python -m http.server 8765 --bind 127.0.0.1 --directory dist` を実行して `http://127.0.0.1:8765/` を開く。

`node tools/build_scenes.mjs` でデータを再構成する。`python tools/generate_audio.py` は対訳台本から音声を生成し、同じ台本・声・設定の生成済み音声を再利用する。スクリプトは `tools/python-packages` のedge-ttsを使用。

元フォルダの絵辞典HTML・画像・録音は変更していない。`dist` が配信ファイル一式、`artwork` は生成原本の保管場所。

## 検証

`tools/verify.mjs` はWindows Edgeと同梱Playwrightで、全場面の移動、全137番号の選択、各場面の日葡実再生、全274 MP3のデコードと音声波形の有無、キーボード操作、拡大・リセット、原画比較、目次、言語設定の保持、深いリンク、390px幅と横向きの横はみ出しを検査する。

結果は `qa/report.json`、各場面のスクリーンショットは `qa/desktop-NN.png` と `qa/mobile-NN.png`、生成イラスト一覧は `qa/all-scenes.jpg`。iPhone・Android実機での確認と音声内容の専門校正は未実施。
